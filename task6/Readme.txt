ANN from Scratch + sklearn: Train an ANN on MNIST using sklearn's MLPClassifier,
experimenting with different hidden layer sizes and activation functions. Plot the training
loss curve over iterations. Then build a 2-layer ANN from scratch in NumPy —
implement forward pass, sigmoid activation, binary cross-entropy loss, and
backpropagation weight updates. Train on a binary classification dataset. Plot the
decision boundary evolution and loss curve. Print and compare sklearn vs manual
implementation results in a table.
