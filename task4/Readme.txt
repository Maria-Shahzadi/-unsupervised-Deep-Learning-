PCA Visualisation + Compression Lab: Apply PCA to the MNIST digits dataset or a
high-dimensional dataset. First standardise the data. Plot the Cumulative Explained
Variance curve and choose the number of components that retain 95% variance. Project
the data to 2D and visualise classes with a colour-coded scatter plot. Then use PCA as a
preprocessing step before K-Means and compare Silhouette Scores with and without
PCA. For image data, reconstruct images from compressed PCA representations using
10, 50, 100, and 200 components and display the reconstructions side by side to
visualise information loss
